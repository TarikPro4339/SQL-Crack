KURULUM
1) ZIP arşivindeki tüm dosyaları aynı klasöre çıkarın.
2) Windows'ta Python 3 kurulu olmalıdır (ek paket gerekmez).
3) SQL_Crack_Baslat.bat dosyasına çift tıklayın.
4) Tarayıcınız kendiliğinden açılır. Açılmazsa CMD penceresinde gösterilen
   http://127.0.0.1:8000 (veya gösterilen başka bir port) adresini açın.
5) Durdurmak için CMD penceresinde CTRL+C tuşlarına basın.
